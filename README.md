## Current work: Shipwreck Discovery

I am **Andrew Rainsberger**, a **Game Developer and 3D Technical Artist** currently contributing to [Shipwreck Discovery](https://shipwreckdiscovery.com/), an underwater VR game for SteamVR and Meta Quest.

<p align="center">
  <a href="https://curiocrafter.github.io/#/projects/shipwreck-discovery">
    <img src="https://raw.githubusercontent.com/CurioCrafter/CurioCrafter.github.io/main/public/images/shipwreck-retopology-proof.webp" alt="Shipwreck Discovery coral PBR result beside validated real-time retopology" width="100%" />
  </a>
</p>

My work connects gameplay systems with the real-time asset pipeline:

- Build and validate coral growth, planting, placement, collision, and wildlife-balance systems in Godot.
- Retopologize coral growth-stage assets, prepare UVs, bake PBR materials, and deliver Godot-ready GLB files.
- Debug VR interaction behavior and add focused regression coverage for gameplay fixes.

`Godot 4` `GDScript` `OpenXR` `Blender` `Python` `GLB / PBR`

[View my contribution case study](https://curiocrafter.github.io/#/projects/shipwreck-discovery) | [Steam](https://store.steampowered.com/app/3583270/Shipwreck_Discovery/) | [Meta Quest](https://www.meta.com/experiences/shipwreck-discovery/32767209856226296/)

TerrainForge generates inspectable terrain tiles and surface data; Laser Saw performs controlled, capped mesh splits; Tidefront Asset Shelf supports repeatable export and catalog workflows. The portfolio evidence comes from installed add-on runs on real geometry, with output checks rather than mock UI.
